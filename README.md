# Dump-N-Done — St. George, UT

Single-page marketing website for Dump-N-Done, a junk removal and hauling service in
St. George, Utah (serving Washington County). Generated by Goose Site Builder.

## Stack

Vanilla HTML, CSS and JavaScript — no build step, no dependencies, no external APIs.
Open `index.html` in a browser, or serve the folder statically:

```sh
python3 -m http.server 8000
```

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Entire single-page site (hero, services, how it works, estimate report, testimonials, contact, footer) |
| `styles.css` | All styling — design tokens, layout, responsive breakpoints, print styles |
| `script.js` | Mobile nav, footer year, estimate-report generator, quote-form validation + submission |
| `favicon.svg` | Site icon |
| `robots.txt`, `sitemap.xml` | Basic SEO files |

## Sections

- **Hero** — business name, tagline, primary CTA ("Get a Free Quote") and pricing card
- **Services** — the eight hauling services offered
- **How it works** — three-step process
- **Free estimate report** — client-side tool that generates a truck-space / price-range /
  diversion report and auto-fills it into the quote form
- **Testimonials** — customer reviews plus a "Leave us a review" link to `/review`
- **Contact** — email, service area, hours, and the quote request form

## Forms

The quote request form posts to LeadrVision:

```
POST https://vision.leadrai.com/api/forms/c47223b829afd076973ba1f079fa9d3b
```

- Works without JavaScript via the plain `action` attribute; the visitor returns with
  `?submitted=1` and the page shows the confirmation message.
- With JavaScript, the same endpoint is called via `fetch()` with a JSON body and the
  confirmation is shown inline when the response is `{"ok": true}`.
- Hidden fields: `_form` (form name), `_page` (set to `window.location.href`),
  and `_gotcha` (honeypot).

## Notes

- `/review` is provided by the hosting platform; this repo intentionally does not
  define that route.
- No image files are used — iconography is inline SVG and the hero uses CSS gradients.
